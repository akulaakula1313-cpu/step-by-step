# Дурак — SANI GROUP Premium

Исправленная версия онлайн «Подкидного дурака» на Node.js + Socket.IO.

## Запуск

```bash
npm install
npm test
npm start
```

Открыть `http://localhost:3000`.

## Что исправлено

- правильный переход атаки после «БЕРУ»: атакует игрок после защищавшегося;
- после успешной защиты защищавшийся становится новым атакующим;
- партия заканчивается только в конце полного боя, а не после отдельного отбивания/атаки;
- добавлен внутренний сброс карт, чтобы карты не терялись из состояния;
- в эндшпиле пропускаются игроки без карт;
- исправлены зависания ботов при отсутствии карт у текущего атакующего;
- исправлена обработка ничьей;
- проверяется сохранность всех 36 уникальных карт.

Важно: рука из более чем 6 карт после «БЕРУ» сама по себе не является ошибкой — это предусмотрено правилами подкидного дурака. До исчерпания колоды после завершения боя игроки с меньшим количеством карт добирают до 6; после исчерпания колоды добора нет.
## Дополнительная общая проверка

`overall_test.js` выполняет 300 случайных полноценных партий для 2, 3 и 4 игроков и проверяет сохранность всех 36 карт, легальность отбивок, лимит атаки, завершение боя и отсутствие зависаний.

Исправлен найденный при этой проверке случай зацикливания `ПАС` при достигнутом лимите подкидываний. Теперь при заполненном лимите бой корректно завершается через `БИТО`.
